## Full Description (4000 characters max)

💰 Finance Tracker — Simple Finance, Mindful Spending

Finance Tracker by Tracking Monk is a complete personal finance app that helps you track expenses, income, savings goals, budgets and recurring transactions — all 100% offline with zero data collection.

✨ KEY FEATURES

💸 TRANSACTION TRACKING
• Add income & expense transactions instantly
• 10+ default categories + create your own
• Edit and delete transactions anytime
• Search and filter by Today / This Month / All Time
• See date, category, and time for every transaction

👥 FAMILY MEMBERS
• Separate wallets for you + 1 family member
• Switch between members instantly
• Each member has independent transactions, budgets & goals

💰 BUDGET MANAGER
• Set monthly budgets per category
• Visual progress bars — track spending vs budget
• Green / Orange / Red indicators as you approach limits
• Edit or delete budgets anytime

🎯 SAVINGS GOALS
• Create goals with target amount and deadline
• Add money to goals progressively
• See days remaining and completion percentage
• Mark goals as complete with celebration

🔄 RECURRING TRANSACTIONS
• Set up daily, weekly, monthly or yearly recurring entries
• Auto-added every time you open the app
• Pause or resume any recurring transaction
• Summary popup showing what was auto-added

📊 ANALYTICS & INSIGHTS
• Category spending breakdown (doughnut chart)
• 7-day daily spending trend
• Monthly comparison charts
• AI-powered spending insights
• Top spending category analysis

📤 EXPORT & IMPORT
• Export as Excel (.xlsx) with summary sheet
• Export as PDF — formatted report with charts
• Export as CSV — opens in any spreadsheet app
• Export as JSON — full data backup
• Import from CSV, Excel, JSON

☁️ BACKUP & RESTORE
• Full backup of all data as JSON
• Restore from backup anytime
• Never lose your financial history

🔒 PIN LOCK SECURITY
• 4-digit PIN protection
• Custom number pad — no keyboard popup
• 5 wrong attempts = 30 second lockout
• Change PIN anytime
• Forgot PIN option

🎨 7 BEAUTIFUL THEMES
• Gold & Navy (default)
• Dark Mode
• Ocean Blue
• Forest Green
• Rose Pink
• Midnight Purple
• Sunset Orange

💱 AUTO CURRENCY DETECTION
• Automatically detects your country's currency
• Supports 50+ countries
• India (₹), US ($), UK (£), EU (€), UAE (د.إ) and more

🔐 COMPLETE PRIVACY
• All data stored ONLY on your device
• Zero data collection — we cannot see your data
• No account required
• No ads, no tracking, no subscriptions
• Works 100% offline
